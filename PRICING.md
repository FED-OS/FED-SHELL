# Pricing

> FED-Shell is **free and open source**. This file documents the optional
> paid services and monetization paths around it — not the software itself.

## The software

| | Price |
|---|---|
| FED-Shell source code | **Free** (open source) |
| Self-hosted builds (your own GitHub repo) | **Free** (GitHub Actions free tier covers most builds) |
| Local builds | **Free** |

You pay nothing to use FED-Shell. Clone it, run it, ship apps.

---

## Optional paid services (future / planned)

### 1. Hosted build API

> *Not yet available — see `ROADMAP.md`*

Send a URL to an API endpoint, get back a download link for all platform
artifacts. No GitHub account needed.

| Plan | Price | Includes |
|---|---|---|
| Pay-per-build | ~$1–5 per build | One URL → all platforms, download link valid 24h |
| Monthly subscription | ~$15–27/mo | Unlimited builds, priority queue, artifact retention |

### 2. FED-PLAY storefront listing

> *Not yet available — see `ROADMAP.md`*

Publish your built apps to the FED-PLAY alternative app store.

| | Price |
|---|---|
| Free listing | $0 |
| Featured placement | TBD |
| Transaction fee | ~5% (if paid apps are supported) |

### 3. Enterprise / white-label

> *Not yet available — see `ROADMAP.md`*

For organizations that want FED-Shell as a private build pipeline with
signing, custom branding, and support.

| | Price |
|---|---|
| Self-hosted (you run it) | Free — it's open source |
| Managed private instance | $500–5,000 / client (TBD) |
| Custom integration / support | Quote-based |

---

## Why it stays free

FED-Shell is part of the FED-OS ecosystem, which exists to give independent
developers a sovereign tech stack free of corporate gatekeepers. The core
build tool will always be free and open source. Paid services, if they come,
will be optional conveniences (hosted builds, store placement) — never a
paywall on the ability to build your own apps.
