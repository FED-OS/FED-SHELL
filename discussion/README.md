# FED-Shell — Discussion Templates & Guides

> Templates and guides for GitHub Discussions categories. Copy these into
> GitHub Discussions when creating categories, or use them as a reference
> for what belongs in each category.

## Discussion categories

FED-Shell uses GitHub Discussions with these categories:

| Category | Purpose | Template |
|----------|---------|----------|
| **Announcements** | Release notes, roadmap updates (maintainer-only) | — |
| **General** | Questions that aren't bugs or features | [`general.md`](general.md) |
| **Ideas** | Proposals for new platforms or capabilities | [`ideas.md`](ideas.md) |
| **Show and tell** | Share apps you've built with FED-Shell | [`show-and-tell.md`](show-and-tell.md) |
| **Q&A** | Build questions, configuration help | [`qa.md`](qa.md) |

## How to set up discussions

1. Enable Discussions in repo Settings → Features → Discussions
2. Create each category above
3. For each category with a template, paste the template content as the
   category's default discussion body
4. Pin the [`DISCUSSION_WELCOME_README`](../.github/DISCUSSION_WELCOME_README.md)
   as a welcome post in the **General** category

## Forum alternative

If you prefer a forum over GitHub Discussions, the FED-OS community forum is
at [fedpromptly.com/forum](https://fedpromptly.com/forum). Cross-posting
between the two is encouraged.
